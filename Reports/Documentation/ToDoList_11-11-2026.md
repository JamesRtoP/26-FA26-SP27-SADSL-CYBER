## Homeserver

### Declutter Main [ ]
Right now all the server routes are sitting in main. This is convenient right now, but makes changing a route semi-difficult. If we could find a way to make these routes functions/make main less cluttered it would be great. 

### Make Homeserver Pretty [ ] 
The homeserver app is currently just the default app for qt creator. Make it look good.

### Homeserver Logging [ ]
A good homeserver desplays current activity. If you work on this ensure that whatever logging process you use is easily extendable in the future for more API endpoints and actions. Any action taken by the host or client applications should be recorded as logs and both displayed and saved to a file. API requests should not be listed as API requests, but instead the actual action they take (i.e. registering, starting a chat, logining in, etc)
