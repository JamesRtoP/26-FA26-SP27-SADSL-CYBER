## Work Summary (Developer Facing)
The main objective for sprint 2 was to implement client application for Q3chat. First we built a bare bones client app that could access the basic REST endpoint we had already implemented in sprint 1. We had to implement true REST endpoints for event handling and starting chats. Once we had the client application hooked up to the server, we implemnted databases in both to ensure data could be saved when they closed. Lastly we revamped the client application so that it looked professional.

## Unfinished Work
We partially completed the key exchange process for encryption. Encryption is the goal for sprint 3 and we were able to complete key storage during sprint 2. Moving forward we will have to complete the handshake and continous communication.
